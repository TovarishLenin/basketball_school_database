# Basketball School Database 🏀

Учебный проект базы данных баскетбольной школы.

База данных предназначена для хранения информации о спортсменах, тренерах, группах, тренировках, спортивных залах и посещаемости.

## Таблицы базы данных

| Таблица | Что хранится |
|---|---|
| `age_categories` | Название возрастной категории, минимальный и максимальный возраст |
| `trainers` | ФИО тренера, телефон, специализация, дата приёма на работу |
| `halls` | Название зала, адрес и вместимость |
| `training_types` | Виды тренировок и их описание |
| `groups` | Название группы, максимальное число спортсменов, тренер и возрастная категория |
| `athletes` | ФИО спортсмена, пол, дата рождения, контакты и группа |
| `trainings` | Дата, время, длительность, статус, группа, зал и вид тренировки |
| `attendance` | Отметки о посещении спортсменами тренировок |

## Связи в базе данных

- одна возрастная категория может включать несколько групп;
- один тренер может вести несколько групп;
- в одной группе может быть несколько спортсменов;
- для группы создаётся расписание тренировок;
- тренировки проводятся в спортивных залах;
- для каждой тренировки указывается её вид;
- посещаемость связывает спортсменов и тренировки.

## Возможности проекта

- создание и заполнение базы данных;
- просмотр списка спортсменов по группам;
- просмотр расписания тренировок;
- учёт посещаемости;
- подсчёт заполняемости групп;
- анализ загрузки залов;
- получение статистики по тренировкам;
- использование представления, индекса, транзакции и подготовленных SQL-запросов.
